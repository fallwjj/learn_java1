# Java学习练习题 / Java Learning Exercises

## 第一周练习 / Week 1 Exercises

### 第1天：Java基础 / Day 1: Java Basics
1. 编写一个程序，输出你的姓名、年龄和爱好
2. 创建一个包含多行注释的Java程序
3. 练习使用不同类型的注释（单行、多行、文档注释）

### 第2天：变量和数据类型 / Day 2: Variables and Data Types
1. 声明并初始化所有8种基本数据类型的变量
2. 练习类型转换：将double转为int，char转为int
3. 创建一个程序计算圆的面积（使用final定义π）
4. 练习字符串与数字的相互转换

### 第3天：运算符 / Day 3: Operators
1. 编写程序计算两个数的所有算术运算结果
2. 使用三元运算符判断一个数的奇偶性
3. 创建一个简单的计算器程序（加减乘除）
4. 练习逻辑运算符的短路特性

### 第4天：条件语句 / Day 4: Conditional Statements
1. 编写程序判断一个年份是否为闰年
2. 创建一个成绩等级判定程序（A、B、C、D、F）
3. 使用switch语句创建一个简单的菜单系统
4. 编写程序判断三个数的最大值

### 第5天：循环语句 / Day 5: Loop Statements
1. 使用for循环打印99乘法表
2. 编写程序找出1-100中的所有质数
3. 使用while循环实现数字猜谜游戏
4. 打印以下图案：
   ```
   *
   **
   ***
   ****
   *****
   ```

### 第6天：数组 / Day 6: Arrays
1. 创建一个包含10个随机数的数组，找出最大值和最小值
2. 实现数组的反转功能
3. 编写程序统计数组中每个元素出现的次数
4. 创建一个简单的学生成绩管理系统（使用数组）

### 第7天：方法 / Day 7: Methods
1. 编写一个方法计算两个数的最大公约数
2. 创建一个方法判断一个字符串是否为回文
3. 实现一个方法对数组进行排序（冒泡排序）
4. 编写递归方法计算斐波那契数列第n项

## 第二周练习 / Week 2 Exercises

### 第8天：类和对象 / Day 8: Classes and Objects
1. 设计一个图书类（Book），包含书名、作者、价格等属性
2. 创建一个简单的图书管理系统
3. 设计一个矩形类，包含计算面积和周长的方法
4. 创建多个对象并比较它们的属性

### 第9天：封装和构造方法 / Day 9: Encapsulation and Constructors
1. 为第8天的图书类添加封装和构造方法
2. 创建一个员工类，使用getter/setter方法
3. 设计一个银行卡类，确保余额不能为负数
4. 实现构造方法的重载

### 第10天：继承 / Day 10: Inheritance
1. 设计动物类层次：Animal -> Dog/Cat -> 具体品种
2. 创建形状类层次：Shape -> Circle/Rectangle -> 计算面积
3. 实现车辆类继承：Vehicle -> Car/Truck -> 具体品牌
4. 练习方法重写和super关键字的使用

### 第11天：多态 / Day 11: Polymorphism
1. 使用多态实现不同形状的面积计算
2. 创建动物发声的多态示例
3. 实现员工工资计算的多态（正式员工、临时工、经理）
4. 练习instanceof运算符的使用

### 第12天：抽象类和接口 / Day 12: Abstract Classes and Interfaces
1. 设计抽象的交通工具类
2. 创建可飞行接口和可游泳接口
3. 实现多个接口的类
4. 比较抽象类和接口的使用场景

### 第13天：异常处理 / Day 13: Exception Handling
1. 创建一个安全的除法计算器（处理除零异常）
2. 设计自定义异常处理用户输入验证
3. 实现文件操作的异常处理
4. 练习finally块的资源清理

### 第14天：集合和泛型 / Day 14: Collections and Generics
1. 使用ArrayList管理学生名单
2. 使用HashMap创建简单的电话簿
3. 实现一个通用的栈数据结构
4. 练习不同集合类型的选择和使用

## 练习提示 / Practice Tips

1. **循序渐进**：从简单开始，逐步增加复杂度
2. **多练手**：每个概念都要通过代码实践
3. **代码审查**：定期回顾和改进你的代码
4. **调试技能**：学会使用调试工具定位问题
5. **代码规范**：养成良好的编码习惯
6. **文档记录**：为你的代码添加适当的注释

## 学习检查点 / Learning Checkpoints

完成每天的练习后，问自己：
- 我是否理解了今天的核心概念？
- 我能否独立编写相关的代码？
- 我是否能解释这些概念给别人听？
- 遇到问题时我知道如何寻求帮助吗？

记住：编程是一门实践性很强的技能，只有通过大量练习才能真正掌握！
